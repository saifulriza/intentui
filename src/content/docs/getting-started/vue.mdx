## Installation
Create a Vue project with Vite:
<InstallCommand command="npm create vite@latest"/>

Install Tailwind CSS and Vue plugin:
<InstallCommand command="npm install tailwindcss @tailwindcss/vite @vitejs/plugin-vue"/>

## Configure Vite
Update your `vite.config.ts`:
```ts
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import tailwindcss from '@tailwindcss/vite'

export default defineConfig({
  plugins: [vue(), tailwindcss()],
})
```

## Phase 1 components (Vue-native)
Phase 1 includes foundational components without React dependencies:
- `Button.vue`
- `Badge.vue`
- `Card.vue`
- `CardHeader.vue`
- `CardContent.vue`
- `CardFooter.vue`

You can copy these from:
`/src/vue/components/ui`

## Use in Vue
Use the components directly in `.vue` files:
```vue
<script setup lang="ts">
import Button from '@/components/ui/Button.vue'
import Badge from '@/components/ui/Badge.vue'
import Card from '@/components/ui/Card.vue'
import CardHeader from '@/components/ui/CardHeader.vue'
import CardContent from '@/components/ui/CardContent.vue'
import CardFooter from '@/components/ui/CardFooter.vue'
</script>

<template>
  <Card>
    <CardHeader title="Vue 3 Native" description="Phase 1 components" />
    <CardContent>
      <Badge intent="success">Ready</Badge>
    </CardContent>
    <CardFooter>
      <Button intent="primary">Button from Intent UI</Button>
    </CardFooter>
  </Card>
</template>
```

## Notes
- These Phase 1 components are Vue-native and do not depend on React, React DOM, or Veaury.
- More interactive components (menu/dialog/select/date, etc.) will follow in next phases.
